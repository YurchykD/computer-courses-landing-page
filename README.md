# Computer Courses Landing Page

A responsive landing page for a computer courses school, built with HTML and SCSS.

**Live demo:** https://yurchykd.github.io/computer-courses-landing-page/

## Overview

A one-page website that presents the courses and encourages visitors to sign up. Built as a personal frontend practice project with a focus on clean layout and mobile-friendly design.

## Tech stack

- HTML5
- SCSS / CSS
- GitHub Pages (hosting)

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/YurchykD/computer-courses-landing-page.git
   ```
2. Open `index.html` in your browser.
